# test: completa testes unitários por componente e aplica cobertura mínima

## O que foi feito

A pipeline executava cobertura sem um mínimo obrigatório, e parte dos componentes tinha apenas cobertura indireta. Esta entrega acrescenta 48 casos para UI, barra lateral, tema, proatividade, alertas, notificações e mensagens, mantendo os testes existentes. A suíte passa com 112 testes em 18 arquivos e exercita os 38 módulos de componentes da interface principal.

O job `frontend-unit` exige 80% de linhas e instruções, 75% de funções e 70% de ramificações, usando a mesma configuração do Vitest local. Um gate por arquivo rejeita componentes com zero execução. O job também executa `typecheck` e publica reports JUnit e Cobertura.

Closes #276

## Como testar

Em `src/frontend`, após `npm ci`:

```sh
npm run lint
npm run typecheck
npm test
npm run test:coverage
npm run format:check
npm run build
```

Medição local em 05/10/2026: **86,36% linhas, 83,96% instruções, 85,81% funções e 75,25% ramificações**. A prova negativa com componente temporário sem teste fez a cobertura sair com código 1 mesmo com os 18 testes de UI aprovados. A fixture foi removida.

[Inventário, revisão e evidências](relatorio-s5-22.md). Relatórios regeneráveis: `src/frontend/coverage/` e `src/frontend/test-results/unit/junit.xml`.
